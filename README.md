# Редактор баннеров Mindbox

Статический редактор баннеров: работает без сборки и без backend.

## Что внутри

- `index.html` — страница редактора.
- `styles.css` — стили интерфейса.
- `script.js` — логика редактора и PNG-экспорта.
- `assets/brand/mindbox-black.svg` — встроенный логотип Mindbox.
- `assets/fonts/` — локальные файлы CoFo Sans.
- `logos/` — папка для библиотеки логотипов.
- `no_cache_server.py` — локальный сервер для проверки без кеша.

## Как проверить локально

Из папки проекта:

```bash
python3 no_cache_server.py
```

Открыть:

```text
http://127.0.0.1:4173/
```

## Как задеплоить

Это обычный статический сайт. На Netlify, Vercel, GitHub Pages или похожий хостинг нужно загрузить содержимое этой папки целиком.

Для Netlify самый простой путь:

1. Открыть Netlify.
2. Создать новый сайт.
3. Загрузить папку проекта или архив.
4. После деплоя открыть выданную ссылку.

Для Vercel или GitHub Pages:

1. Положить файлы в репозиторий.
2. Настроить деплой из корня репозитория.
3. Build command не нужен, output directory — корень проекта.

## Библиотека логотипов

Если нужны логотипы в библиотеке, положите SVG/PNG в `logos/` и заполните `logos/logos.json`:

```json
[
  {
    "name": "befree",
    "src": "logos/befree.svg"
  }
]
```

## Важно про шрифты

В архив включены файлы CoFo Sans. Перед публичным размещением проверьте, что у команды есть право использовать и распространять этот шрифт в таком виде.
